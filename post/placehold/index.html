一、服务简介与优势

placehold.co 是一个简单、快速且免费的图片占位服务。只需通过 URL 就能按需生成指定尺寸、格式、颜色和文字的占位图，无需注册、无需 API Key、无需下载任何资源。

主要优势：

  • 零门槛：纯 URL 驱动，浏览器、代码、设计稿中直接引用即可。
  • 免费快速：服务免费，生成速度快，适合开发调试与设计排版阶段使用。
  • 灵活定制：尺寸、格式、背景色、文字色、文字内容、字体、清晰度均可自定义。
  • 多格式支持：SVG、PNG、JPEG、GIF、WebP、AVIF 六种格式任意切换。
  • SVG 默认格式：默认输出 SVG，矢量无损、体积小，适合原型与文档插图。

二、URL 构成解析

placehold.co 的 URL 遵循以下基本结构：

https://placehold.co/{宽度}x{高度}.{格式}/{背景色}/{文字色}?text={文字}&font={字体}

各部分说明：

组成部分 位置 说明 是否必填
基础域名 路径起始 https://placehold.co 必填
尺寸 路径第一段 {宽度}x{高度}，如 600x400 必填
格式 尺寸后缀 .svg / .png / .jpg / .gif / .webp / .avif 可选，默认 SVG
背景色 路径第二段 {背景色}，如 22c55e 可选
文字色 路径第三段 {文字色}，如 ffffff 可选
查询参数 问号之后 text=、font= 等 可选

注意：颜色（背景色、文字色）必须成对指定，两者需同时出现。

最小示例

https://placehold.co/600x400

即生成一张 600×400 像素的默认 SVG 占位图。

三、尺寸控制

3.1 基本尺寸

使用 宽度x高度 格式指定尺寸：

https://placehold.co/600x400.png

3.2 方形（省略高度）

高度可以省略，此时自动生成正方形：

https://placehold.co/600.png

等价于 600x600。

3.3 尺寸限制

  • 最大尺寸：4000 x 4000 px
  • 最小尺寸：10 x 10 px

超出范围时服务可能无法正确生成，请控制在上述区间内。

四、格式选择

4.1 支持的格式

支持以下六种格式：

格式 后缀 特点
SVG .svg 默认格式，矢量无损、体积小，适合原型与文档
PNG .png 位图，支持透明背景，适合 UI 设计稿
JPEG .jpg 位图，体积较小，适合照片类占位
GIF .gif 支持简单动图场景占位
WebP .webp 现代网页格式，压缩率高
AVIF .avif 最新一代高效图片格式

4.2 在尺寸后追加格式

格式作为尺寸段的扩展名，直接拼接：

https://placehold.co/600x400.png
https://placehold.co/600x400.jpg
https://placehold.co/600x400.webp

4.3 格式与颜色组合

格式可以与颜色同时使用，例如：

https://placehold.co/600x400.png/22c55e/ffffff

五、颜色配置

背景色与文字色放在路径第二段、第三段，用 / 分隔。两者必须成对出现。

5.1 十六进制颜色值

最常用方式，直接使用十六进制值（不需要 # 前缀）：

https://placehold.co/600x400/22c55e/ffffff

上例：背景色 #22c55e（绿色），文字色 #ffffff（白色）。

5.2 CSS 颜色名称

支持使用 CSS 颜色名替代十六进制值：

https://placehold.co/600x400/orange/white

上例：背景色 orange，文字色 white。

5.3 透明背景

使用 transparent 关键字可以得到透明背景：

https://placehold.co/600x400.png/transparent/000000

透明通常配合 PNG 等支持透明通道的格式使用，效果最佳。

六、自定义文字

6.1 通过查询参数设置文字

使用 text 查询参数自定义图片上的文字：

https://placehold.co/600x400?text=Hello+World

6.2 空格用 + 表示

URL 中的空格用 + 表示：

https://placehold.co/600x400?text=Hello+World

渲染结果文字为 Hello World。

6.3 换行用 \n 表示

需要换行时，在 text 参数中使用 \n：

https://placehold.co/600x400?text=Line1%5CnLine2

6.4 默认文字

默认文字为图片的尺寸。例如 https://placehold.co/600x400 默认会在图上显示 600 x 400。

七、字体配置

7.1 通过查询参数设置字体

使用 font 查询参数指定字体：

https://placehold.co/600x400?font=roboto

7.2 默认字体

默认字体为 Lato。

7.3 可用字体

服务内置了多种开源字体可供选择（如 Roboto、Montserrat、Oswald、Raleway 等 Google Fonts 常用字体）。字体名通常使用小写形式，如 lato、roboto、montserrat。

提示：具体可用字体清单以服务官方文档的 “The following fonts can be used” 列表为准，使用前建议在服务页面确认支持情况。

7.4 字体与文字组合

字体参数可与文字参数自由组合：

https://placehold.co/600x400?text=Hello+World&font=roboto

八、Retina 高清

8.1 通过 @2x / @3x 获取高清图

在尺寸后追加 @2x 或 @3x，即可获得高分辨率版本，适配 Retina 屏：

https://placehold.co/600x400@2x.png
https://placehold.co/600x400@3x.png

8.2 适用格式

仅以下格式支持 retina 图片：

  • PNG
  • JPEG
  • GIF
  • WebP
  • AVIF

SVG 不支持 retina 后缀（SVG 本身为矢量，无需高清倍数）。

十、常见使用场景

10.1 前端开发

  • 组件开发阶段用占位图替代真实图片，避免依赖外部素材。
  • 布局调试时快速验证响应式尺寸（结合不同宽度 URL）。
  • 单元测试 / 截图对比时使用固定 URL 保证可复现。

10.2 UI / UX 设计

  • 设计稿中占位 Banner、卡片配图、头像位，不阻塞视觉评审。
  • 用颜色参数快速模拟品牌色在版面上的呈现。
  • 用 Retina 版本确认高清屏下的显示效果。

10.3 文档与演示

  • README、API 文档中插入示意图片。
  • 技术方案 / PPT 中使用统一风格占位图。

10.4 原型与 Mock

  • 直接以 SVG 格式嵌入 HTML，矢量缩放不失真。
  • 通过 text 参数标注模块用途（如 “Banner”、“Avatar”）。

十一、长期可用性分析与替代兜底建议

11.1 可用性分析

  • 服务性质：第三方免费公共服务，稳定性与可用性由官方维护决定，不提供 SLA 承诺。
  • 风险点：
    • 免费服务可能调整策略、限流或下线。
    • 依赖外部网络，内网 / 离线环境不可用。
    • 生成结果可能因服务端更新产生细微差异。
  • 适用定位：适合开发、设计、原型、文档等非生产场景；生产环境依赖占位图时需谨慎。

11.2 替代兜底建议

方案 说明
自建占位服务 用本地脚本（如 ImageMagick、sharp、Pillow）按需生成，完全可控
前端动态生成 Canvas / SVG 在浏览器端实时绘制占位图，零外部依赖
其他在线占位服务 如 dummyimage.com、via.placeholder.com 等同类服务作为备选
静态资源本地化 一次性生成所需占位图，随项目打包，彻底消除运行时外部依赖

建议：在长期项目中，将占位图作为临时过渡方案，并在关键文档中注明替换路径。

十二、常见问题（FAQ）

Q1：尺寸必须带高度吗？

不必。省略高度会生成正方形，如 https://placehold.co/600 等于 600x600。

Q2：最大/最小尺寸是多少？

最大 4000x4000 px，最小 10x10 px。

Q3：默认输出什么格式？

默认格式为 SVG。

Q4：背景色和文字色必须一起设置吗？

是。两者必须成对指定，不能只设置其中一个。

Q5：颜色值需要带 # 吗？

不需要。直接写十六进制值即可（如 22c55e），也支持 CSS 颜色名和 transparent。

Q6：图片默认显示什么文字？

默认显示图片的尺寸，如 600 x 400。

Q7：文字里的空格和换行怎么处理？

空格用 +，换行用 \n（URL 中可编码为 %5Cn）。

Q8：默认字体是什么？

默认字体为 Lato，可通过 font 参数更换。

Q9：SVG 支持 Retina 吗？

不支持。仅 PNG、JPEG、GIF、WebP、AVIF 支持 @2x / @3x。

Q10：可以用在生产环境吗？

可临时使用，但第三方免费服务不保证 SLA，生产环境建议自建或本地化占位资源。
