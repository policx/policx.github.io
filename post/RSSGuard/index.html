RSS Guard 桌面 RSS 阅读器

2026-08-01 • 4 分钟阅读 • Software

为什么又聊 RSS

2026 年了，算法推荐统治了信息获取，但 RSS 不但没死，反而在技术圈悄悄复兴。原因很简单——把信息筛选权拿回自己手里，不被平台投喂牵着走。

在试过 Inoreader、Fluent Reader、QuiteRSS、NewsFlash 之后，我最终把主力换成了 RSS Guard，用了大半年，把心得整理出来。

RSS Guard 是谁

一个基于 Qt 框架的开源 RSS/Atom 阅读器，GNU GPL v3 协议，GitHub 仓库 martinrotter/rssguard。最新稳定版 5.2.1，原生 Windows / Linux / macOS 全平台。

核心亮点一句话：极小、极快、极少打扰。

安装后的第一印象

打开就是经典三栏布局——订阅源列表、文章列表、阅读面板，没有花哨的欢迎页和引导动画。安装包体积不到 30MB，内存占用稳定在 50~80MB，对一台整天开着 IDE 和几十个浏览器标签页的开发机来说几乎无感。

七个让我留下的功能

1. 多后端支持

RSS Guard 不只是个 RSS 客户端，它内置了多种账号后端：

后端 说明
标准 RSS/Atom 直接订阅源 XML
Google Reader API 对接 Inoreader、FreshRSS、Miniflux 等自建服务
Tiny Tiny RSS 老牌自建 RSS 服务
Nextcloud News Nextcloud 生态的新闻组件
Gmail 把邮件当 Feed 读

对于同时使用 FreshRSS 自建服务 + 本地直连订阅的我来说，一个客户端搞定所有源，不需要来回切换。

2. 规则引擎 + 自动过滤

这是 RSS Guard 真正拉开差距的地方。内置了一套完整的消息过滤规则系统，支持：

  • 按标题/正文/作者/分类正则匹配
  • 自动标记已读、星标、删除
  • 基于规则自动分配标签

举个例子：我订阅了 Hacker News 的 RSS，但不想看 Show HN 和 Ask HN，一条正则规则 ^(Show HN|Ask HN) 直接自动标记已读，信息流清爽一半。

3. 内置 WebEngine 渲染

某些订阅源只给摘要不给全文，RSS Guard 可以内嵌 Chromium（Qt WebEngine）直接在阅读面板里打开原文，不需要跳转外部浏览器。配合「一键提取全文」功能，大多数摘要源能直接拉取完整正文。

4. 快捷键全键盘操作

每一个操作都可以绑定快捷键。习惯了之后整个阅读流程不用碰鼠标：

j/k     → 上/下一篇文章
m       → 标记已读/未读
s       → 星标
v       → 在新标签页打开原文
Ctrl+U  → 标记以上全部已读

对键盘党极度友好。

5. 离线全文搜索

所有抓取过的文章内容落地到本地 SQLite 数据库，支持正则全文搜索。断网状态下也能翻历史文章，比必须联网的在线服务踏实得多。

6. 通知与托盘

支持按订阅源粒度配置桌面通知，新文章到达时 Windows 原生通知弹窗。系统托盘图标可以显示未读数角标，最小化到托盘后完全不占任务栏空间。

7. 导入导出无锁定

支持 OPML 标准导入导出，换客户端零成本。数据目录是纯 SQLite 文件，迁移就是复制粘贴一个文件夹。

三个目前不够好的地方

  1. UI 算不上漂亮。Qt 原生控件，风格偏朴素，和 Fluent Reader 那种现代 Electron 界面相比有代差。好在功能压倒形式。

  2. 移动端缺失。RSS Guard 只有桌面版。手机端需要搭配 FreshRSS / Miniflux 等服务端，再用移动端 App（如 Reeder、NetNewsWire）读取同一后端。

  3. 同步需要服务端。如果你只在单台电脑上使用，本地模式足够；多设备同步必须配置 Google Reader API 兼容的服务端，对新手有一定门槛。

我的推荐配置组合

桌面端：RSS Guard（主力阅读 + 规则过滤）
服务端：FreshRSS（Docker 自建，24h 在线）
移动端：Reeder Classic（iOS）/ FeedMe（Android）

三者通过 Google Reader API 同步，任何一端标记已读或星标，其他端秒级同步。

适合谁

  • 订阅源超过 50 个，需要高效批处理阅读
  • 对信息质量有洁癖，需要规则过滤噪声
  • 偏好本地优先、隐私可控
  • 不介意花 15 分钟做初始配置

不适合谁

  • 只需要关注 3~5 个源 → 浏览器书签栏就够了
  • 追求现代设计感 UI → 试试 Fluent Reader
  • 完全不想折腾配置 → Inoreader 免费版

最后

RSS Guard 不是最漂亮的 RSS 阅读器，但可能是功能最扎实的那一个。它像一个工具箱——打开时不惊艳，但每次用都能找到恰好趁手的工具。

开源项目维护者是 Martin Rotter，一个捷克开发者，从 2014 年做到现在。这种十年如一日打磨一个工具的项目，值得被更多人知道。
